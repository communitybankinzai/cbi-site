あなたのPRを公開する

あなたの「できること」を書いておくと、人手を探している団体から声がかかります。 CBIの人材バンクは、この「あなたのPR」でできています。

はじめかた

  1. CiDAOに登録する

    市民参加アプリ「CiDAO（シダオ）」にLINEでログインします。ニックネームで登録でき、 メールアドレスも電話番号も入力は不要です。

  2. 「公開PRの編集」を開く

    マイページから公開PRの編集に進みます。資格や経験、興味のあること、 力になれそうなこと、活動できる時間帯（平日昼・平日夜・土日昼・土日夜・オンラインのみ）を入力します。 書けるところだけで構いません。

  3. 公開範囲を自分で決める

    公開範囲は「完全公開」「登録ユーザーのみ」「連携同意者のみ」から選べます。 声がけの受け取り方も「誰からでも」「AI推薦経由のみ」「受け付けない」から選べるので、 まずは狭い範囲から始めても大丈夫です。

  4. 団体からの声がけを受け取る

    保存すると人材バンクの一覧に掲載されます。あなたの興味分野と重なる団体は自動で提案されるので、 気になる団体があれば自分から参加を申し込むこともできます。

PR MOVIE / IMAGE

この機能を紹介するSNS投稿用の動画・画像は準備中です。
