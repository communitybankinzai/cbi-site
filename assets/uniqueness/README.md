# site/assets/uniqueness/

このフォルダは uniqueness ページで使う画像置き場。

## 必要画像

### dao-concept.png（DAO思想図：中心に自動化、周縁に人間）

- 用途：`site/uniqueness/index.html` 末尾の「CiDAOとは？」脚注セクションに表示
- 推奨アスペクト比：1:1（正方形）
- 推奨サイズ：800x800px 以上
- 形式：png（背景透過 or オフホワイト #faf8f3）
