CiDAO 使用量削減・機能整理・個人情報対策の報告

2026年11月6日の朝に CiDAO（cidao.vercel.app）が無料枠の超過で停止したことを受け、同日に「使う量を4分の1減らす」「余計なものを減らす」「情報を漏れにくくする」の3つを実施した記録です。

実施日 2026-11-06 対象 CiDAO・防災マップ 作成 A1 Core（Claude）・承認 運営
要約背景何を測ったか1. 使う量2. 余計なもの3. 個人情報・安全利用者に見える変化確かめたことこれから

要約

使う量（CPU時間）
約 1/4 減 の見込み

検索ロボットの制限・重い処理の使い回し・配信側の保存の延長・巡回の時刻集約・防災マップの読み直し間隔。効果は11月13日ごろに実測で確認。

余計なもの
API 4本削除

使われていない入口を閉じ、成果の薄い自動取り込みを週1回に。利用の少ない3画面をメニューから外した。

個人情報・安全
7 件の是正

会員情報の読み取り範囲、鍵なしの入口、位置記録の期限、土台ソフトの重大な欠陥、DBパスワードの変更ほか。

利用者の見た目はほとんど変わりません。地図の情報が最大で数分遅れて出ることがある点と、メニューが少し減った点だけです。

背景

なぜ急いで実施したか

  • CiDAO は Vercel の無料プランで動いており、「CPU を使った時間」が月4時間の枠を8月末から超え続けていた。11月6日 5時03分に自動停止し、同日 7時35分に有料プラン（Pro・月20ドル）へ切り替えて復旧した。
  • 有料にしても使う量が多いままでは費用がかさむため、運営の指示で「使う量を4分の1ほど減らす」改修を同日に行った。
  • あわせて、同時期に報道された不正アクセス事件（FXサービスの顧客情報流出、開発用リポジトリの認証情報漏えい）を踏まえ、個人情報の扱いを点検した。

1. 使う量を減らす（5つ）

観点前後
検索ロボットの巡回制限なし。来るたびに CPU を使っていたGoogle・Bing と SNS の見出し取得だけ許可。AI 学習用や SEO 業者のロボットは拒否。API・管理・本人の画面は全ロボット拒否
重い処理（水位・冠水・通れた道・情報源の状態・避難所）見るたびに毎回計算1〜10分の間は前の結果を使い回す（県・市・外部サイトへ取りに行く間隔は変えていない）
配信側の保存15秒〜2分市の固定データや告知画像は1日、巡回系は5分、運休・消防見張りは1分
裏の巡回の起動時刻1時間に6回ばらばら1時間に2回（:00 と :30 の前後）にまとめ、起こす回数を減らした
防災マップの読み直し常に10分ごと。在席の合図は2.5分ごと平常時は15分ごと・合図は5分ごと。注意報・警報が出ている間は今までどおり10分ごと

見込み：平常日 約630秒/日 → 約470秒/日（無料枠の水準）。検索ロボットの割合が推定のため、確信度は「中」。

2. 余計なものを減らす

対象前後
使われていない API 4本残っていた（うち1本は鍵なしで誰でもメールを送れた）削除
毎朝の自動取り込み5本が毎日動き、下書きが118件たまっていた号外NET は停止。Instagram のタグ検索と市のカレンダーは週1回（月曜朝）。団体アカウントと文化ホールは毎日のまま
利用の少ない画面ランキング・AIに相談・AIインタビューがメニューにあった（30日の閲覧 17・23・1回）メニューから外した。URL を知っていれば今までどおり開ける

3. 個人情報・安全

漏れる経路を減らし、漏れても被害が広がらないようにした

前後
会員テーブルの全28列を、ログインしていない人でも一括で読めた（通知の設定・最終アクセス・運営かどうか など。本名・メールは別に守られていた）未ログインは表示名・自己紹介など公開項目だけ。会員同士も通知設定や認証方式は見えない。本人の画面は変わらない
裏の巡回を起動する入口 4本に鍵がなく、誰でも起動できた合言葉がないと動かない
「通れた道」の記録に端末の識別子が無期限で残っていた30日で消す。線のデータは残す
土台ソフト（Next.js）に、外から侵入される重大な欠陥が複数残っていた（修正版は出ていた）最新版に更新（画像処理の部品も更新）
DB のパスワードが、過去の開発履歴に残っていたパスワードを変更し、関係する設定をすべて新しい値に。古い値はもう使えない。未使用の秘密キーも失効
公開サイトの作業記録に担当者の携帯番号が残っていた伏せた
（問題なしと確認）本名・メールの保護、受付・声がけ・通知の読み取り制限、書き込み時の IP の90日削除、非公開の写真・動画の保管、鍵の直書きなし変更なし

利用者に見える変化

  • 防災マップの情報が、最大で数分遅れて出ることがある（警報中の避難情報は2分以内、避難所は5分以内）。
  • メニューから「ランキング」「AIに相談」「AIインタビュー」が消えた（URL は生きている）。
  • それ以外は同じ動き。会員のログイン・プロフィール保存・通知設定も変わらない。

これから

  • 11月13日ごろ：Vercel の画面で日別の CPU 時間を読み、11月6日の前後で比べる（目標 約470秒/日）。足りなければ、ロボット遮断の強化・巡回間隔の見直し・固定ページの静的化を検討する。
  • 公開ファイルに載っている個人のメールアドレスを伏せるかは、運営の判断待ち。
  • プロフィール保存の「処理中」表示（押してから数秒なにも起きないように見える）は、優先度低で予定に登録。
