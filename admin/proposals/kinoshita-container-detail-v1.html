結論

「コンテナ運営」は、観光ツアーの収益不足を補う“箱の事業”になりうる。ただし儲けの源は『コンテナ1棟を自分で建てて貸す』ではなく、『市・受託事業者が設置した箱の運営（貸出・管理・広告）を受け持つ』ことにある。 自己資金でコンテナを建てる形は避けるのが前提（確信度：中）。

7-3 対応方針（案）

  1. 飲食は自営しない。 許可・食中毒の責任・設備投資を負わない。許可を持つ事業者に月・半年で貸す。
  2. 飲食仕様の棟は1〜2棟に集約（給排水・排気・グリストラップを一度で整える）。残りは非飲食。
  3. 日・週貸しは非飲食を基本。飲食の日貸しは、①許可持ちのキッチンカーの乗り入れ枠、②持ち込み販売（許可は借り手側）に限る。営業者ごとの許可の要否は保健所に確認してから。
  4. FreeFree型（無料喫茶）は後回し。 先に保健所で「無料・広告つきの扱い」を確認する。
  5. 酒類は出さない（当面）。
  6. 借り手の義務を契約に書く： 営業許可証の写し、食品衛生責任者、PL保険、アレルゲン表示、清掃、夜間・強風時の片づけ。
  7. 試行（武蔵屋のイベント等）では、飲食は既存の許可施設（aebe）に任せる。 新規の許可は取らない。

16. 市の担当者の視点：想定される指摘と答え（税金を使う判断として・11-10 追記）

市と受託契約を結ぶ 自治体の委託契約では、成果物の著作権を市に帰属させる条項が標準的なことが多い（一般論・中）。ただし受託者が前から持つ著作物は、受託者に権利を残して市に利用を許す形が一般的。精霊は既存の著作物として扱える
市が公式グッズを作る 譲渡ではなく、非独占の利用許諾（期間・範囲・品質基準つき）
譲渡すると 精霊の商品展開や他地域への展開を自由にできなくなる。市が他の事業者に作らせることも可能になる

契約書に「成果物の著作権は市に帰属」とあれば、精霊は対象外と明記する。印西市の契約書の条項は未確認。

18-3 グッズは公募か、許可制か

型 向く場面 見込み
許諾制（申請→承認・いんザイ君と同じ型） 民間の事業者・団体が自分で作って売る 推奨。 申請書式・使用料の有無・品質ガイド・表示の義務を決める。権利者は CBI（または作者）
調達（市が買う・配る物品） 市のノベルティ・景品 公募ではなく市の調達ルール（入札・見積合わせ）。少額の随意契約の基準は未確認。精霊の利用許諾は別に出す
公募（製作・販売権の募集） 市が独占的な事業者を選びたい場合 精霊では勧めない。権利を持たない市が募集すると、権利関係が崩れる

いんザイ君は市のキャラクターで、使用承認制（承認は2027-03-31まで。使用条件に、生成AIでの描き直し・反転・色変更の禁止と、著作権表示2行の記載がある）。精霊は市のキャラクターではないので、市の使用承認の枠には入らない。

18-4 決めておくこと（11月中）

  • 精霊の作者・権利者は誰か（個人か CBI か）を、本人が確認する。
  • CBI 代表との議題：精霊の帰属と、N's factory への使用許諾。
  • 利益相反の手続き：CBI の会計担当が製作を請け負うため、理事会の承認と、当事者が議決に加わらないことが要る（記録済み）。
  • 生成サービスの規約（商用利用の可否）の確認。
  • 市への確認（11/14 の後でも可）：受託契約の標準契約書で、既存の著作物の扱いはどうなるか。
