CiDAO β — https://cidao.vercel.app

印西市の参加と貢献の循環基盤（市民DAO）の本番アプリ。LINEログイン → 提案・投票・議論・イベント・団体・人材バンク・FreeFree 応援掲示板 が利用できます。スマホ／PC 両対応（PWA、ホーム画面追加可）。

📋 はじめての参加手順（3 ステップ・約 90 秒）

  1. https://cidao.vercel.app を開き「ログイン」をタップ
  2. 「LINEでログイン」をタップし、LINEアカウントで認可するだけ（初めての方は自動でアカウント作成）
  3. ログイン後、ホーム画面の 6 機能（提案・議論・マイページ・イベント・団体・FreeFree）を試す

※ 初回ログインで「ライト登録」（重み 0.1）として自動作成されます。マイページから「プロフィール編集」で氏名・住所などを登録し本登録申請すると「LINE登録のみ（ハガキ未受領）」（重み 0.3）に、運営が郵送ハガキの受領を確認すると「住所確認済」（重み 1.0）に昇格します（仕様書 v2.1）。

⚠️ β 期間の既知の制限（重要）

  • 2FA 未設定：GitHub / Supabase / Vercel の二要素認証が未導入。本格運用前に対応予定
  • AI 機能はスタブ：提案分類・団体マッチングは keyword 簡易判定（LLM 差替待ち）
  • メール／SNS 通知未実装：Resend / X / Facebook / LINE への配信は API キー取得後に対応
  • 本登録の住所確認フローは運営が手動処理：上位 tier（重み 1.0）への昇格は、運営が郵送ハガキの受領を管理画面で確認する方式（仕様書 v2.1。JPKI／マイナンバーカード連携は Phase 2+ で検討）
  • /admin 運営画面未実装：投票期間調整等の管理操作はまだ DB 直編集
  • 重要な意思決定には未使用推奨：拘束的決議の本格運用は CBI 運営委員会承認後
